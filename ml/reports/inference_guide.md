> **Synthetic Data Disclaimer**: This inference service operates on synthetic data for food redistribution simulation. All metrics, outputs, and parameters represent synthetic-data experiments.

## 1. Output Contract Schema

Every prediction generated by the Model A inference service adheres strictly to the JSON schema defined in `ml/reports/prediction_contract.md`:

```json
{
  "ngo_id": "N001",
  "forecast_date": "2026-10-25",
  "predicted_meals": 80.7,
  "baseline_prediction": 72.2,
  "model_version": "random_forest_v1",
  "is_fallback": false,
  "confidence_lower": 54.8,
  "confidence_upper": 107.8,
  "disclaimer": "Synthetic-data experiment for operational redistribution planning only."
}
```

### Schema Field Definitions:
- `ngo_id` (`str`): Unique identifier of the recipient NGO.
- `forecast_date` (`str`): Target forecast date formatted as `YYYY-MM-DD`.
- `predicted_meals` (`float`): Final model demand forecast (non-negative, rounded to 1 decimal place).
- `baseline_prediction` (`float`): Same-weekday 4-week average heuristic benchmark prediction.
- `model_version` (`str`): Semantic identifier of the active model (`random_forest_v1`).
- `is_fallback` (`bool`): `true` if cold-start policies were triggered (e.g. unknown NGO or empty history), else `false`.
- `confidence_lower` (`float`): 10th percentile empirical prediction across tree estimators.
- `confidence_upper` (`float`): 90th percentile empirical prediction across tree estimators.
- `disclaimer` (`str`): Standard operational compliance notice.

## 2. Python API Usage

```python
from rescuebite_ml.predict import DemandPredictor

# Initialize predictor (loads serialized pipeline & metadata)
predictor = DemandPredictor()

# 1. Single Forecast
result = predictor.predict_one(ngo_id="N001", forecast_date="2026-10-25")
print(f"Predicted meals: {result['predicted_meals']} [{result['confidence_lower']} - {result['confidence_upper']}]")

# 2. Batch Forecast
targets = [
    ("N001", "2026-10-25"),
    ("N002", "2026-10-25"),
    ("N003", "2026-10-26"),
]
batch_results = predictor.predict_batch(targets)
```

## 4. Cold-Start & Uncertainty Protocol

### A. Unknown NGO ID
When an unknown NGO is queried:
1. Static attributes fall back to `"unknown"` type and median values.
2. Missing lag and rolling features are imputed via the pre-fitted training median imputer.
3. `is_fallback` is explicitly set to `true`.
4. Output predictions are clipped at $\ge 0.0$.

### B. Empirical Uncertainty Intervals
Rather than assuming Gaussian errors, the inference engine computes empirical percentiles directly across all individual decision trees in the Random Forest ensemble:
$$\text{confidence\_lower} = \max(0.0, P_{10}(\hat{y}_{\text{trees}}))$$
$$\text{confidence\_upper} = \max(\text{confidence\_lower}, P_{90}(\hat{y}_{\text{trees}}))$$

This provides redistribution planners with an immediate confidence bound reflecting tree agreement and historical volatility.
